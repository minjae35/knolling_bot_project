# v2.0.0

The annotated tag `v2.0.0` is object `c9924d3` and points at commit `593bd5d`. That commit is also the tip of `dev/knolling-v3`. From `5efca4b` to `593bd5d`, the inference sources are unchanged. The tag commit adds `experiments/end_to_end/score_holdout.py`, this release record, and the demo gallery. `v2.0.0-rc1` points at commit `d96c40e`. `v1.0.0` points at commit `26dca53`.

`main` has moved past `593bd5d`. Later commits stop tracking the local `archive/` tree and move the arrangement implementation from `src/knolling_model/recovery/` to `src/knolling_model/arrangement/`, leaving import shims so existing perception checkpoints resolve. The 640-scene table below was not measured again after the tag.

Do not train on, tune a threshold against, or select a checkpoint with `artifacts/v2_independent_eval` or the official 2,000-scene test split. Further training needs a new development set and a separate final test.

## Official holdout

Measured once, under the same evaluator, on the 128 `v2hold_` families (640 samples). This is not comparable to the older official test number. The criterion and the scoring command are in [evaluation.md](evaluation.md).

| | full | partial | no-op | overall |
| --- | --- | --- | --- | --- |
| v1.0.0 | 287/384 | 84/127 | 118/129 | 489/640 (76.4%) |
| v2.0.0 | 311/384 | 104/127 | 125/129 | 540/640 (84.4%) |

v2 kept every v1 success and added 51 (full 24, partial 20, no-op 7). The family-bootstrap 95% interval for the difference is +4.8 to +11.6 percentage points. Twenty-nine families improved and none got worse.

## Inference

RGB is a 576 × 384 BEV image, passed as a float tensor `[B, 3, 384, 576]` in `[0, 1]`. The English sentence selects the task:

- full: starts with `Arrange all objects`
- partial: `Arrange only the red objects`, or green, or blue
- no-op: `Keep every object at its current position and orientation.`

`load_adopted` in `experiments/end_to_end/score_end_to_end.py` loads the frozen weights. `poses_from_detection` then returns target `x`, `y`, and `theta`. The foreground threshold is 0.5. `/tmp/size_head.pt` is not loaded.
