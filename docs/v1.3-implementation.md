## Policies and determinism

`teacher_legacy.py` preserves the exact baseline implementation bytes. Existing
Python callers default to `legacy_v1_2`; callers selecting v1.3 use the explicit
`balanced_rows_v1.3` policy. This prevents silent reinterpretation of old data.
The new policy generates sequential and balanced partitions with k=1..N_selected,
deduplicates by observable-order index tuples, and ranks globally by the specified
rounded scores. Partial candidates use exact polygon validation; the legacy SAT
gap test is sufficient but not necessary and could discard a lower-movement
diagonal candidate. The M5 predicates themselves are unchanged.

An observed-row template requires at least two selected objects, axes within 5°
of a common table axis, row block centers agreeing within 5.1 mm, horizontal gaps
>=9.9 mm and mutually consistent within 5.1 mm, separated row bands, and exact
requested size order/color purity/contiguity. New direction/gap/region are not
required of the old arrangement. This conservative operational definition avoids
inventing existing rows from scattered singleton objects. It is not a claim that
the scene has a known interactive history. These tolerances follow existing M5
row/axis/gap limits, with 0.1 mm numerical allowance.

New vertical targets use -pi/2. Immutable sources, locked poses and no-ops retain
their exact original representation, including legacy +pi/2. Migration compares
physical angles modulo pi and centers with 1e-12 m tolerance; representation-only
changes do not require a new image. All raw and canonical target hashes are kept.

The policy/config hash is distinct from the code revision. No schema fields or
dataclass meanings are changed. Audit/policy/review information goes in sidecars.

## Preliminary Partial coverage

The 30 original Partial samples select 1/2/3/4 objects in 11/11/2/6 samples.
All originally selected objects move. Eleven single-object examples are useful
for grounding/keeping other objects, but do not supervise pairwise knolling.
The current source-generation process produces scattered arrangements; organized
source episodes and multi-turn coverage are not established by geometric validity.
Migration preserves this distribution; any proposed additions require a separate
dataset change rather than silent resampling.
