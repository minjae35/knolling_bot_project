# Archive

These files are kept so earlier experiments can still be read. They are not the
v2.0.0 system.

- `docs/` holds the S0, recovery, perception, and StructDiffusion notes that used
  to sit in `docs/`. The same notes are also on `archive/e2e-failed-experiments`.
- `experiments/` holds rejected recovery helpers that are not on the inference path.

`reference/neural-sequential/` stays at the repository root. It is a frozen
copy of an earlier pose decoder, not the live package. Tests import
`knolling_model.experiments.neural_sequential`.

Do not treat numbers in `docs/` as the v2 holdout result. That result is in
`docs/evaluation.md`.
